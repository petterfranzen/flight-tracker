# Agent tasks

Self-contained briefs for cloud sessions. Start one from any device with:

> Do `docs/agent-tasks/<file>.md`.

Every brief assumes the guardrails in `docs/cloud-agents.md`: work on a
branch, open a PR, never push to or merge into `main` (a push to `main`
deploys to production). Delete a brief in the PR that completes it.

Start each brief with a `Model:` line: `sonnet` for well-specified work
(the default), `opus` only when the brief still needs investigation or
design. See "Working cost-effectively" in `docs/cloud-agents.md`.
